# OwnTake v0.1.0

<!-- lang:en -->
## OwnTake's first desktop release

Turn your ideas into your own films. OwnTake is a local AI film workbench for one creator: develop a story and script, review shots, prepare media, arrange the timeline and export an MP4.

### Features

- A story library with immutable story and script revisions, project links and source attribution.
- Storyboard editing, candidate selection and media imports, with image, video, speech and batch generation workflows.
- A unified OpenAI connection and account model discovery, alongside configurable protocol-compatible providers and optional local CLI draft runtimes.
- A timeline with captions and separate audio tracks, rendered locally through FFmpeg.
- Desktop apps for macOS, Windows and Linux, with native file dialogs, background jobs and project recovery after restart.

### Fixes and release improvements

- Restored the desktop validation workflow and updated its navigation for the current settings tabs and CLI setup form.
- Made release validation portable across Windows line endings and short/long filesystem path aliases.
- Fixed macOS packaging when signing credentials are absent; empty credentials no longer become invalid certificate paths.
- Added early script syntax validation and publication checks for a complete, consistent set of native packages.

### Getting started

1. Install the package matching your operating system and CPU.
2. Configure a model connection, FFmpeg, ffprobe and a subtitle font in Settings. These tools, fonts and model credentials are configured separately.
3. Create a project, develop a story and review the script and shots. Import or generate media, arrange it on the timeline, then export an MP4.

Provider access, supported model capabilities and usage charges depend on your account and connection. Review model proposals before applying them. This release does not include a reusable character library or automatic story collection from Zhihu/Xiaohongshu.

## OwnTake 首个桌面版本

**把你的想法，拍成你的作品。** OwnTake 是面向个人创作者的本地 AI 短片工作台：从故事和剧本开始，审阅分镜、准备素材、编排时间线，最终导出 MP4。

### 新增

- 故事库与不可变的故事、剧本版本，保留作品与故事来源之间的关联。
- 分镜编辑、候选素材选择和素材导入，以及图片、视频、配音和批量生成流程。
- 统一 OpenAI 配置与账号模型发现，同时保留兼容协议的模型连接和可选的本机 CLI 草稿运行时。
- 时间线、字幕与独立音轨，通过本地 FFmpeg 导出 MP4。
- macOS、Windows、Linux 桌面应用，支持原生文件选择、后台任务和重启后的项目恢复。

### 修复与发布改进

- 修复桌面验证脚本，并适配新版设置标签页与 CLI 安装表单。
- 修复 Windows 换行与文件系统长短路径别名造成的验证误报。
- 修复未配置签名凭据时的 macOS 打包错误，空凭据不再被当作证书路径。
- 提前检查脚本语法；只有完整、来自同一源提交且通过原生验证的安装包才能发布。

### 首次使用

1. 下载并安装与你的系统和 CPU 对应的安装包。
2. 在设置中配置模型连接、FFmpeg、ffprobe 和字幕字体；应用包不内置这些工具、字体或模型密钥。
3. 创建项目，编写或选用故事，审阅剧本与分镜；导入或生成素材，编排时间线后导出 MP4。

模型权限、支持的能力与费用取决于实际连接和账号；模型建议需要审阅。本版本不包含可复用人物库，也不包含知乎、小红书故事自动采集。
