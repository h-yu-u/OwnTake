# P3 实现与验证记录

## 本阶段结果

图片 / 视频适配器、付费意图台账、远端任务恢复、不可变候选、技术与人工审核、字幕、独立音轨和本地合成已接通。代码支持 OpenAI Images 与 Ark 视频任务协议；具体模型名、端点和能力由连接配置决定，连接仍标为 `unverified`，不会把协议测试当成真实账号验收。

## 使用路径

1. 设置中添加图片或视频连接，填写实际模型、端点、输入方式、画幅与支持时长。图片协议目前支持纯文字生成；视频支持配置许可的纯文字、首帧、首尾帧或多参考图。能力不兼容会要求重新规划，不会丢弃引用或改写画幅。
2. 分镜中点击「生成候选」，审阅镜头版本、提示词、所发图片顺序、模型目标和费用预留，再提交一次。预留是用户认可的记账金额，不保证是供应商实际费用上界。
3. 任务页可查看原任务、暂停 / 继续查询、关联未知视频提交的原任务 ID、恢复原结果下载并人工核对费用。不同币种分开计算；推理与生成共用项目额度。
4. 完成的结果先成为候选。查看实际素材、记录人工复核并明确采用后，才能进入镜头时间线。视频缩略图来自本地实际抽帧，未成功抽帧时显示占位图标。
5. 分镜保存到时间线时生成镜头字幕，保留最近保存的独立音轨与输出设置。工作台可修改字幕位置 / 颜色 / 字号、音频入点 / 时长 / 增益 / 淡入淡出，再保存为新的时间线版本。
6. 字体使用系统字体或设置中选择的 TTF / OTF / TTC 绝对路径。字体探测报告文件可用性和字体族，不声称已覆盖全部文字。中文显示需目标机器有相应字形；建议配置包含所用文字的字体。
7. 冻结时间线后导出 MP4。独立音轨与启用的片段原声一起混合；浏览器中的素材试听是原音，最终字幕和混音以导出文件为准。

## 恢复与边界

| 情况 | 实际处理 |
| --- | --- |
| 重复点击同一提交 | 稳定操作 ID + 请求摘要，只建立一次意图和额度预留 |
| POST 已发出但响应丢失 / 服务中断 | `submission_unknown`，保留预留，不自动重新 POST |
| 已拿到视频远端 ID | 重启后查询同一个 ID；编辑镜头不改变该任务的冻结输入 |
| 图片回复完整收到、入库前中断 | 先记录大小 / SHA256，保存完整接收文件或 `.part`；重启从匹配文件恢复，不再调用供应商 |
| 图片回复未完整保存 | 保留残片并报告无法恢复；同步图片协议不能凭空重新下载，不能以自动重新生成代替恢复 |
| 视频断流 / 返回 HTML 错误页 | 半下载清理，已完成但无效的文件隔离保留；只重新查询和获取原远端输出 |
| 输出 URL 过期 | 查询原远端任务获取可用地址；供应商已清除结果时仍需人工处理 |
| 取消已提交的 Ark 任务 | 当前 DELETE 同时承担删除已完成记录，GET 后 DELETE 仍有竞态，因此不自动发送非条件 DELETE；提示到供应商端处理，继续查询并保留完成结果，只有确认 cancelled 才终结 |
| 停止查询 | 仅暂停本地查询，不代表供应商已停止工作或停止计费 |
| 旧视觉版本迟到结果 | 入库为原视觉版本的候选，不覆盖当前所选版本 |
| 技术检查通过 | 仅说明文件、媒体信息、尺寸 / 时长的相应检查；画面语义、完整动作和声音仍未检查 |

下载器限制协议、大小、超时与重定向，解析并固定实际连接的公有 DNS 地址；同源回环 HTTP 仅用于显式配置的本地模型端点。输出下载不携带 API Key 或 Cookie。媒体文件、来源输入和字体摘要在导出前核验；字体先复制到本次任务目录，再核验副本并渲染。

schema 升级到 3。备份支持已登记媒体以及数据库快照中可关联的完整未登记图片接收文件；恢复要求大小、SHA256 和派生路径一致。旧 v1 / v2 备份仍可恢复与迁移，凭据继续独立保管。
