# P1 实现与验证记录

## 交付

本阶段交付可独立运行的本地 Web 应用：Vue 3 / TypeScript / Naive UI 界面、Node 24 本地服务、SQLite 项目与持久任务、FFmpeg 媒体管线。全流程不需要配置模型。

- 新建项目，导入真实视频、图片、音频，查看媒体信息及预览。
- 时间线排列、入点/时长、画幅/帧率、留边/裁切和源音轨静音，保存不可变版本。
- 导出持久任务、真实进度、停止、同一操作去重，输出 H264/AAC MP4。
- 同名文件独立入库；缺失文件可恢复，必须与原素材 SHA256 一致。
- 回环地址、会话和 CSRF、受控媒体地址、范围请求、路径/符号链接边界。
- SQLite WAL、嵌套事务、事件、版本冲突、备份和向空目录恢复。
- 工具路径设置、FFmpeg/ffprobe 健康检查；上传前磁盘余量检查。

## 验证环境与结果

实际环境为 Linux，Node 24.22.1、npm 11.9.0、FFmpeg/ffprobe 6.1.1。运行 `npm test`，**21 项测试全部通过**；TypeScript/Vue 类型检查与 Vite 生产构建通过。

| 验证 | 实际结果 |
| --- | --- |
| 真实 HTTP 导入→冻结时间线→导出 | 通过，输出尺寸/时长/编码经探测 |
| 重复提交、版本冲突、会话/来源/CSRF | 通过，未产生重复任务 |
| 删除源文件、错误文件恢复、原文件恢复 | 缺失 409、内容不一致 422、正确文件恢复成功 |
| 服务重启 | 项目与结果保留；模拟持久 `running` 状态恢复到重新执行并成功 |
| 真实媒体管线 | 混合尺寸、视频/图片、入点、片段颜色顺序、源声音、静音、帧率验证通过 |
| 工具缺失、格式拒绝、越界裁切、取消/超时 | 明确失败或取消，未发布半成品 |
| 浏览器端到端 | Chromium 153 实际点击新建、上传、加入片段、保存、导出及刷新；数据库确认恰好 1 个成功导出，页面无 JS 异常 |
| SQLite 一致性 | 幂等、事务回滚、乐观锁、路径约束、未来 schema 保护通过 |

中间片段使用 MOV/H264/PCM，最终统一编码 AAC，避免逐段音频编码延迟以及毫秒时间基导致的帧率偏差。最终产物在事务中登记，取消与发布之间再次核验任务状态。

## 本次未验证的项目

- 目标 Mac 上的安装、播放器人工观看、机器睡眠/断电行为。
- `running` 恢复测试模拟的是数据库中断状态，不等于 SIGKILL/断电实验。宿主被强制终止后，旧 FFmpeg 可能短暂继续；旧临时文件不会登记为可用作品，下一次执行使用独立目录。不要把这一点描述为完整孤儿进程回收。
- 浏览器测试环境缺少中文系统字体；没有把该环境截图视为目标 Mac 字体/播放器视觉验收。
- 当前预览使用浏览器原生媒体元素，未实现批量离线缩略图缓存。

这些项目保留为目标设备验收项；用户要求连续完成开发，因此后续代码阶段继续进行，不将外部环境验收冒充已通过。

## 使用

参见仓库 [README](../../README.md)。默认服务 `http://127.0.0.1:4317`，开发界面 `http://127.0.0.1:5173`。关闭页面不会停止服务；明确退出服务会停止本地子进程，并保留可恢复任务。密钥不属于这一阶段的功能。
