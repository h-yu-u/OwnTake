> 状态：代码与本地验证已完成，见 [P4 验证记录](../validation/p4.md)。此次选择配音、有限抽帧审核、Claude Code / Codex 草稿运行时和诊断；字幕样式、音量与淡入淡出已在 P3 接通。主要覆盖 FR-19、FR-20。真实账号与目标 Mac 验收仍独立记录。

> 配置体验补充：新增 [OpenAI 统一连接](../validation/openai-connection.md)，一次填写 API Key 管理推理、图片与配音，保留单协议兼容连接和原有执行流程。

> 模型选择补充：支持 [账号模型发现](../validation/openai-model-discovery.md)、按用途搜索及手填回退，新连接的默认模型更新，已有选择与冻结任务保留。

> 设置导航补充：媒体工具、OpenAI、其他模型连接、本机 CLI、本机工作区分别通过标签页切换，各模块复用独立组件和原有保存流程；切换标签保留未提交输入，桌面诊断归入本机工作区。

## 目标

根据真实制作中的重复操作提升效率。优先解决最常见的编辑、声音和审核问题，再决定是否把 Claude Code、Codex 等运行时接进来，不为了“多 Agent”增加固定流程。

## 前置条件

- P3 MVP 已能稳定制作短片，并有实际使用记录。
- 当前最费时间或最影响成片的操作已经明确。
- 现有 schema、素材版本与任务恢复测试可以用于回归。

## 可独立选择的交付包

| 交付包 | 范围 | 建议模块 |
| --- | --- | --- |
| 编辑增强 | 更顺手的裁切、镜头连接、字幕样式、音量与淡入淡出；按需扩展轨道 | `apps/web`、`packages/media`、`packages/domain` |
| 音频增强 | 可选 TTS、配音管理、字幕对齐；输入音频和生成音频能力分别声明 | `packages/providers`、`packages/media` |
| 语义审核 | 抽帧/视频/音频检查、时间点证据、规则与人工决定 | `packages/runtimes`、`packages/providers` |
| Agent 运行时 | 可选 Claude Code/Codex 适配器，受限的宿主工具与结构化计划输出 | `packages/runtimes`、`apps/server` |
| 运行诊断 | 更清楚的工具路径、认证状态、上下文与进程错误 | `apps/server`、`apps/web` |

无需全部完成才获得收益。每次只选择一个存在明确使用价值的包，交付后用真实作品验证。

## 实施顺序

1. 记录上一阶段实际作品中最常见的返工点，选一个增强目标。
2. 先定义该功能需要的新输入、输出、依赖与审核覆盖，不绕开旧版本和预算语义。
3. 编辑增强继续编译到受控时间线与 FFmpeg 参数，不允许模型直接拼接任意终端命令。
4. 语义审核保持只读，输出检查对象、时间点、证据与不确定项；修复建议单独成为待应用计划。
5. 接入外部运行时时，自动查找本机 Claude Code / Codex，供用户选择 CLI、模型与推理强度；路径和超时保留高级设置。强度缺省保持模型默认，显式强度随配置冻结并传给 CLI。执行仍绑定绝对路径、`cwd` 和白名单环境，不依赖交互式 shell；模型来源与未验证的认证状态明确展示，检测不自动启用或提交模型请求。
6. 运行时通过受限工具调用宿主能力；预算、文件范围、任务记录和计划应用仍由 OwnTake 控制。
7. 用旧项目、旧导出与已有异常场景做针对性回归，补充兼容迁移和使用说明。

CC/Codex 是 Agent 执行环境，不是与视频模型同类的模型名。把推理模型换成另一家供应商，不自动获得相同的文件工具、上下文管理或进程生命周期。运行时适配器必须说明实际可支持的任务。

宿主能够限制经自身接口的调用，但配置 `cwd` 和工具白名单不自动构成第三方 CLI 的操作系统沙盒。无法保证其全部权限时，应把它作为用户显式启用的可信本机扩展，标明自带工具与凭据边界，不宣称具有硬隔离能力。

## 验收情景与失败测试

| 情景 | 通过条件 |
| --- | --- |
| 开启新的字幕/音频能力 | 旧时间线与素材仍可打开；新增依赖只影响对应输出 |
| TTS 或审核调用失败 | 现有配音/审核不被覆盖，能够继续人工完成作品 |
| 只检查了少量帧 | 报告列出采样范围，不能自动宣称动作/声音均合格 |
| 审核提出修改建议 | 只形成计划，未经项目授权不自动生成新费用 |
| CC/Codex 不存在、未登录或退出异常 | 有具体诊断；用户仍可用原生/手工流程 |
| 运行时通过宿主请求越界文件或额外工具 | 宿主拒绝并记录；外部 CLI 自带工具的额外权限单独说明，不混同为宿主沙盒 |
| 外部运行时中断后重启 | 重新关联已有任务；模型生成仍遵守未知提交处理 |
| 替换运行时 | 相同领域任务与素材版本继续可读，不迁移为某工具私有项目格式 |

## 本阶段不做

为了支持外部 Agent 而引入任意系统控制、多用户权限平台或无限自主循环。也不追求完整专业非线性剪辑软件、自动修复一切质量问题或所有模型能力的统一最低公分母。

## 退出门槛

所选择的增强在至少一个真实作品流程中减少了操作或改善了结果，新增能力有清晰边界且没有破坏 P3 的恢复与成本语义。未被验证有用的增强可继续搁置。是否进入 P5，取决于是否确实需要更方便的启动与后台管理。

## 2026-11-08 补充：分镜批量配音

分镜页、独立音轨和创作工具提供批量配音入口。自动填入每镜字幕台词，可逐镜修改 / 勾选，统一选择连接、声音、语速与风格；默认跳过空台词、同版本已有配音和进行中 / 待核对任务。一次登记后台队列，刷新 / 关闭浏览器继续执行；完成后显式一键加入时间线，按镜头起点摆放配音，延长图片镜头并顺延字幕，不截断声音。原视频不足时提示调整；旧素材、台词与时间线版本保留。无需手动费用表单，重复登记和重复加入分别去重。验证与真实供应商限制见 [P4 验证](../validation/p4.md)。

## 2026-11-08 补充：批量添加已有音轨

独立音轨区新增“批量添加音轨”，支持音频搜索、多选、筛选可添加素材与试听；按分镜对齐、依次接入、同时播放三种排列均提供起止位置预览。连续播放可调整顺序与统一起点。已有素材跳过，异常输入整批拒绝，图片延长沿用配音对齐逻辑；不产生新模型调用。加入后仍保存时间线再导出，原单条添加入口保留。

## 2026-11-08 补充：音轨变更后的成片更新提示

导出页区分当前编辑与冻结成片，音轨或剪辑改变后提示“当前播放的仍是旧成片”，可直接重新导出；新产物完成后预览自动更新，保留旧版文件。避免把此前静音成片误认为已包含新增配音。

## 2026-11-08 补充：素材剪辑工作区整理

素材库、预览和编辑区在桌面视口内排列，画面、字幕、独立音轨通过标签切换；各区设定最大高度，长列表内部滚动，保存入口固定在编辑区底部。画面仅保留横向顺序时间线及当前片段设置，移除重复的纵向片段列表；选择片段继续同步预览和素材库。字幕、音轨各显示紧凑列表及一个当前条目的设置，切换标签保留编辑状态。手机端素材库可折叠，编辑区高度受限；已有批量入口、保存和刷新恢复保留。具体检查及限制见 [P4 验证](../validation/p4.md)。

## 2026-11-08 补充：创建配音试听与简化

单条创建配音新增试听播放器，支持当前全文或空白时的示例句，并使用当前声音、语速和风格。生成结果可反复试听并直接加入音轨，无需再生成一份。移除配音的本地费用预留表单及两项确认勾选，点击生成即可登记；保留简短的服务计费说明。已知结果按连接版本和输入复用，登记回复丢失使用原标识查询，未知供应商结果不自动重发。弹窗内容限制高度并内部滚动，操作栏保持可见；其他创作工具的预留流程不变。

## 2026-11-08 补充：创作工具与任务中心分工

创作工具移除批量配音记录和操作台账，只保留功能入口与查看任务链接。任务中心通过图片与视频、分镜配音、创作记录、导出与处理四个标签分块，面板最大高度受限，长列表内部滚动。批次汇总与逐镜详情分别展示，详情默认折叠；普通创作记录排除批次成员。已有停止、试听、恢复入库、费用核对、候选复核和加入音轨入口随记录搬迁。新提交自动定位相应任务标签，切换保留查看状态；不新增模型调用或更改后台协议。

## 2026-11-08 补充：从分镜直接选择本机 CLI

已启用 CLI 可直接出现在分镜推理下拉框中，沿用已保存模型与推理强度，不自动启用或改认证。分镜弹窗和创作工具的 CLI 草稿入口均无需填写本地预留或额外勾选确认，仍产出独立待审阅草稿；未知结果不自动启动第二次 CLI。旧任务的预留与已冻结配置保留。

## 2026-11-08 补充：素材库聚焦画面

左侧素材库及数量只展示图片与视频，音频统一从独立音轨入口选择、试听和批量添加；已有文件及时间线音轨保留。纯音频项目显示画面素材空态，导入入口仍支持音频。验证记录见 [P4 验证](../validation/p4.md)。


## 2026-11-08 补充：抽样审核表单简化

抽样帧审核弹窗移除本地费用表单及两项确认勾选，连接与候选有效即可提交。接口允许省略预留，新记录不显示不存在的预留金额；旧任务金额及显式预留合同继续保留。修正相同属性刷新导致候选和请求标识重置的问题，保留本地去重、未知供应商结果不重发、冻结历史候选要求及人工选用流程。验证见 [P4 验证](../validation/p4.md)。
