# P7：合规故事发现与来源引用

- 后端使用知乎官方站内搜索 `zhihu_search` 与官方授权全网索引 `global_search` + `host=="xiaohongshu.com"`，不伪装登录、不使用站点 Cookie 和 HTML 爬虫。
- 配置只通过本机进程变量 `OWNTAKE_ZHIHU_ACCESS_SECRET` 注入，不存入项目数据库、日志、API 响应或 Git。
- 所有上游请求限制为固定官方 HTTPS 域名，单次至多 10 条、12 秒、1 MiB，不跟随重定向；不自动重试可能产生费用的请求。
- 返回只保留标题、链接、作者和有界摘要；过滤来源域名，规范化 URL，拒绝重复收藏。
- 无授权和无法检索时仍可手动保存链接；只登记灵感，不自动改编、不存储第三方全文。
- SQLite Schema v6 为来源 URL 创建唯一索引；旧库自动迁移并作数据库快照。
- UI 提供来源切换、关键词检索、打开原帖和手动收藏。

本阶段的测试使用离线 HTTP 假服务；**不以虚拟数据声称已验证真实知乎 Access Secret**。
