# P3 · 可靠生成闭环与自用 MVP

> 状态：代码已实现并通过本地契约 / 媒体验证，见 [P3 验证记录](../validation/p3.md)。真实供应商账户、实际账单和目标 Mac 验收待执行；不将这些尚未完成的外部条件标为通过。覆盖 FR-09–FR-16，完善 FR-02、FR-05、FR-08、FR-18。

## 目标

把图片/视频模型接入已有分镜和媒体系统，让每次付费调用、每个候选与最终成片都能追溯，并在页面关闭、服务重启或网络不确定时保持可恢复的状态。

## 前置条件

- P1 的本地文件、任务、媒体和导出已验收。
- P2 的分镜、修订、能力清单、计划和候选选择合同稳定。
- 选择至少一个可实际访问的图片模型连接与一个视频模型连接，确认认证、输入、异步任务、费用与结果期限。具体模型不在设计文档中写死。
- 定义有限的真实调用测试预算；故障注入使用模拟供应商，不为测试制造重复扣费。

## 范围与建议模块

| 模块 | 交付行为 |
| --- | --- |
| `packages/providers` | 真实图片/视频适配器、能力约束、请求编译、提交/查询/取消/结果获取 |
| `packages/domain` | 生成意图、尝试、费用预留、任务事件、审核绑定与失效 |
| `packages/storage` | 冻结输入、SQLite jobs、预算/事件事务、下载入库和恢复记录 |
| `apps/server` | 有限并发调度、恢复入口、SSE、素材服务与连接诊断 |
| `apps/web` | 执行前摘要、任务页、未知提交核对、候选比较与审核 |
| `packages/media` | 基础字幕、导入音轨、生成素材接入既有时间线与输出 |

先完成一个真实能力切片，验证合同后再扩大范围；同一供应商可以同时提供图片和视频能力，无需为了数量接入第二家。可替换性先用能力不同的模拟适配器验证。接口相同不等于能力相同，不能只换 `baseURL` 就标记接入完成。

## 实施顺序

1. **验证与编译。** 能力描述精确到供应商、API 版本、模型和端点；根据输入方式与条件约束验证计划。记录验证状态与时间，拒绝不支持的输入组合。
2. **提交前事务。** 在 SQLite 中冻结计划与输入版本，创建稳定的生成意图/操作标识、费用预留和待执行任务。校验项目授权、单次上限、累计上限和并发。
3. **外部提交。** `validate`/`compile` 保持纯函数；`submit` 单独执行。供应商支持幂等键时绑定稳定操作标识；不支持时也不能在超时后盲目重发。
4. **恢复语义。** 有远端任务 ID 就恢复查询；可能已受理却没有可靠关联时进入 `submission_unknown`。界面提供核对远端任务或保留待处理，不把“重新生成”当成网络恢复。
5. **轮询与取消。** 按适配器的实际语义查询、退避、请求取消，保留最后确认状态。关闭页面不等于取消；取消不等于免费；停止查询不等于远端已停止。
6. **结果入库。** 远端成功后立即获取输出，下载至临时文件，探测/校验后原子发布并登记不可变素材版本。下载失败只重试下载；旧修订结果归入原候选。
7. **审核与选择。** 首先提供技术检查与人工预览；审核绑定素材/计划/规则版本。用户选择候选后更新镜头所选版本，不能自动覆盖已选作品。
8. **基础成片。** 加入基础字幕和导入音轨，确定性渲染文字，支持局部字幕/音量修改。冻结时间线后继续复用 P1 的渲染与导出。
9. **验收作品。** 制作 4 镜头混合素材短片，记录每个生成结果、所选版本、预算状态、导出和恢复验证。

费用字段区分估算、预留、已确认与未知。不同币种分别计量。未知状态保留预留；明确失败也可能已经收费，是否释放额度取决于实际证据和用户处理记录。

## 必须通过的异常矩阵

| 故障或操作 | 通过条件 |
| --- | --- |
| 首尾帧计划改用仅首帧模型 | 提交前拒绝；可选择重新规划，不静默丢弃尾帧 |
| 点击两次提交或事件重复投递 | 同一意图不会重复建立可计费提交 |
| 供应商受理后响应丢失 | 进入未知状态；服务重启后也不自动新增可能计费的尝试。只有明确上游幂等保证时，才按原键、原请求及有效窗口安全核对或重传 |
| 已知远端任务运行时本地服务退出 | 重启后查询原任务，不创建新任务 |
| 浏览器离开或机器睡眠 | 恢复后按实际远端状态继续，不能误报完成/取消 |
| 供应商成功但下载断开 | 结果仍属于原任务，恢复下载不会重新生成 |
| 下载链接过期或磁盘满 | 明确提示可恢复条件，半文件不登记为成品 |
| v1 生成中用户编辑到 v2 | v1 结果保存为历史候选，不把 v2 标记完成 |
| 提交后请求取消 | 继续确认远端状态；费用独立显示，保留已产生结果的可能性 |
| 额度不足或价格不明 | 在提交前要求可审阅的额度处理，不先执行再报错 |
| 只改字幕或音量 | 不产生新图片/视频调用，只使相关渲染版本过期 |
| 抽帧检查未包含音频/完整动作 | 对应项目显示未检查或需人工判断，不生成虚假通过 |
| 导出时仍有缺失或未选素材 | 阻止导出并定位镜头；确认修复后导出冻结的新时间线 |

这些风险优先使用确定性故障适配器验证。真实供应商只执行必要的成功闭环、能力与结果验证，记录实际模型和 API 条件。

## 本阶段不做

所有供应商全面覆盖、复杂多 Agent 自主拍摄、自动无限重试、专业多轨剪辑、全自动艺术质量评分、云端队列、桌面打包。用户仍可使用手工输入与人工审核完成作品。

## 退出门槛

[总计划中的 MVP 完成定义](../implementation-plan.md#5-mvp-的统一完成定义)全部满足。能独立导出短片且完成上述恢复验收，才进入日常使用。没有验证过的供应商能力、实际费用和审核范围明确保留为未知，而不是补成看似完整的成功状态。
