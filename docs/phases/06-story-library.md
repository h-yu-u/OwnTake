# P6：故事资产库

- 全局故事独立于具体 Project；标题、题材、摘要、标签与结构节点可搜索并修改。
- 每次修改生成不可变 StoryVersion；剧本以 ScriptVersion 保存，可绑定历史 StoryVersion。
- 一键创建项目时登记来源故事与剧本版本，不会因为后续修改故事而改变既有项目简报。
- 不允许对无明确改编授权的外部内容直接创建作品，来源信息与权利标记持久化。
- SQLite 迁移版本 5；旧库启动前按已有机制创建数据库迁移快照。
- Web 增加「故事库」，具有创建、筛选、版本编辑、剧本保存与转作品入口。

验证：运行 `npm run check`，故事库合同测试验证版本冲突、授权边界、HTTP 会话/CSRF、持久化。

## 2026-11-08 · 布局优化

- 移除重复页边距和独立蓝灰配色，与应用主题统一；索引卡片展示概要、中文来源标记、少量标签与版本信息。
- 默认打开第一篇已有故事，右侧按故事设定、剧本、创建作品三个标签切换，桌面两栏内部滚动，保存栏常驻；手机索引和编辑区均有最大高度。
- 搜索保留当前编辑身份与输入；保存故事不丢弃未保存剧本。离开未保存故事时提示确认，创建作品前显示所用版本并要求先保存当前输入。
- 沿用现有存储与授权合同。此次实际执行的检查和边界见 [P6 验证记录](../validation/p6.md)。
