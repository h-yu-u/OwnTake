# P8：人物库与不可变虚拟演员形象

- 全局 Character 存身份、背景、固定外貌、风格和 TTS 声音预设；档案采用乐观版本控制。
- 上传静态 PNG/JPEG/WebP 并用 FFprobe 确认其为有效静态图，限制 16 MiB、300–6000 px；每次上传产生不可变 CharacterVisualVersion。
- 造型 CharacterLook 绑定具体形象版本，包含服装和情绪，不重复创建演员身份。
- ProjectRole 冻结形象版本、造型、角色名，并复制独立图像为该作品的 Artifact；跨项目不直接共享任意文件路径。
- 由于参考图单张最多 16 MiB，第一版存入 SQLite BLOB，随数据库快照/备份一起校验恢复；普通大媒体仍保存在项目文件目录。后续可在保持版本合同的前提下迁移为内容寻址磁盘仓库。
- SQLite v7 新增全局人物、形象、造型、项目演员关联；HTTP 原始图片流沿用有界上传插件和 Cookie/CSRF 保护。
- Web 人物库本阶段提供创建、编辑、定型、造型与项目演员绑定，不支持覆盖锁定版本；角色解绑与项目角色改版留待审计型流程。
- 测试：人物锁定版本不变、跨作品资产互不影响、重绑冲突、SQLite 备份恢复保留参考图。
