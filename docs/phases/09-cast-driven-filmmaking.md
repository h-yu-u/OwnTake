# P9：剧本转分镜 + 出场人物绑定 + 参考图生成

## 一条完整可审阅的流程

1. 从故事库选择确定版本的剧本，创建作品（登记故事来源和剧本版本）。
2. 点击「根据剧本创建分镜草稿」：纯函数根据场景标题/段落拆分，不调用 LLM、不直接改写正在制作的分镜；用户逐项审阅和接受。
3. 在人物库上传图片或从已有项目的 AI 生成图片直接导入，锁定参考图并绑定作品（独立项目 Artifact），无需重复付费调用。
4. 在分镜的「人物绑定」选择当前镜头角色，生成新的镜头视觉修订并添加不可变参考图。
5. 图片生成选择 OpenAI Image Edits 适配器，调用 `/images/edits`，按 JSON `images:[{image_url:dataUrl}]` 传入图片；视频继续复用 Ark 的首帧/多参考图流程。
6. 提交前审阅计划、预算、费用未知状态和全部参考图；生成记录冻结角色 ID、视觉版本、造型和实际项目素材 ID。

## 验收与约束

- 人物每镜最多四位，引用素材总数最多16。人物绑定与镜头修订在同一同步事务中落盘，校验乐观锁版本。
- 未声明参考能力时禁止将人物参考静默丢弃；`openai-images` 文生图仍拒绝引用；图片编辑要求静态 JPEG/PNG/WebP。
- 每次付费 POST 保留已有幂等与未知提交状态；媒体生成结果仍需用户审阅，不对当前模型声称一致性已获保证。
- 演员身份、造型变化不会改写历史任务。新增 SQLite v8 ShotCastBinding，只引用注册资产，无新的外部目录。
- 无真实收费模型和第三方改编授权，不会自动调用或绕过平台使用权限；剧本拆镜为确定性结构操作，并非 AI 对故事的语义理解。

运行 `npm run check`（原有完整测试+新增故事脚本、人物绑定、参考图片编译及安全测试）。
