# 媒体、批量流程与创作工具

## 责任与数据流

`packages/media/` 探测/校验文件并编译确定性的 FFmpeg 操作；时间线引用已登记资产和明确时间区间。服务端 application 协调导入、导出、批量语音和 Studio 操作，Runner 负责生命周期和恢复。

上传通过有界流进入临时目录，核验格式、大小、媒体信息、路径与摘要后发布资产。FFmpeg 使用参数数组与受限输入协议，不把用户文字直接当作 shell 或未转义的滤镜程序。

## 时间线、字幕与音频

画面、字幕和独立音轨是不同轨道；入点、时长、帧对齐、增益及淡入淡出需在实际素材/片长范围内。字幕字体由用户选择，缺失字体要报告，不把缺字成片视为成功。导出冻结时间线和所需配置，用户后续编辑不改变正在导出的任务。

批量图片、视频与配音仍由多个有身份的操作组成；部分成功必须可追溯，不能将整个批次视为一笔可盲重试的请求。配音批量入轨必须明确落点与时间线版本。

## Studio 与 CLI

Studio 保存配音、抽样审核和可选 CLI 草稿的操作台账。Claude Code/Codex 运行时需明确启用和配置；只接收允许的结构化结果，不能因为模型输出建议就执行任意工具。抽样审核只说明实际帧覆盖，不能声称审核完整视频运动和声音。

FFmpeg、ffprobe、字体、CLI 以及模型凭据均不随桌面包内置；[桌面](desktop.md)与[发布说明](../operations/release.md)必须一致说明这一边界。

## 验证

使用 FFmpeg 生成的小媒体检查探测、混流、字幕、音轨、导出文件可解码与时长。重启恢复、慢上传中断、缺失源素材及批量部分失败需保留。真实人耳/画面审阅与自动探测不等价。
