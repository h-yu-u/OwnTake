# 前端工作区

## 责任

[WorkspaceApp](../../apps/web/src/WorkspaceApp.vue) 装配全局导航、项目选择和功能状态；`views/` 表达页面，`components/` 复用具体交互，`composables/` 管理有生命周期的状态和数据请求，`lib/` 保存 API 客户端与纯辅助函数。复用 Vue 3、TypeScript 和 Naive UI，不再另造表单/弹窗基础库。

## 交互合同

故事库独立于当前项目；分镜、素材剪辑、创作工具、任务和导出按当前作品组织。项目切换和离开编辑前处理未保存内容；后台刷新不能悄悄覆盖用户输入。版本冲突保留编辑内容并给出重新载入/合并方向，不用“自动刷新”掩盖丢失。

生成前展示实际模型、输入、引用素材与能力冲突；单镜图片 / 视频生成不再展示本地费用表单或重复确认框，点击提交后自动完成本地校验，通过后只登记一次请求。校验失败保留输入并说明问题，校验期间禁止重复提交；镜头或连接版本变化会作废迟到校验结果。弹窗内容限制高度并在内部滚动，操作按钮固定在底部，避免错误提示收起时移动导致点击落空。能力不足不能在前端擅自降级。进度、等待远端、未知、失败和需要人工审阅是不同状态。

[API 客户端](../../apps/web/src/lib/api.ts) 统一会话、CSRF、错误合同，不将密钥放入浏览器持久存储。桌面调用只能经过受限桥；Web 使用者不能依赖 Electron 才有的能力。

兼容连接表单在输入 Key 后自动读取模型目录，模型选择支持搜索与手填回退。`useProviderModelCatalog` 管理输入防抖、取消与迟到回复隔离；列表刷新不改写模型选择或手动能力。选中已登记的 Seedance 模型后，按官方文档和当前适配器范围自动填入能力并展示摘要，手动字段收进高级设置；已有手动调整保留，可显式恢复自动配置。未知模型保留原手填入口，不套用上一个模型的参考图片设置。目录与草稿 Key 随弹窗关闭清理，更换来源要求重新填写 Key；协议及凭据约束见 [模型连接与生成](providers-generation.md)。

## 可访问性与验证

单段和分镜批量配音共享中文音色标签，展示听感 / 用途参考及原始英文 ID，支持按中文或 ID 搜索。标签只用于选择提示，不是官方性别或风格保证；可选项仍严格来自当前连接的声音清单，自定义 ID 保持原样，提交与试听使用原始 ID，不自动改写风格指令。[OpenAI 音色列表](https://developers.openai.com/api/docs/guides/text-to-speech#voice-options)是声音 ID 依据，中文描述由应用提供，实际效果以试听为准。

按钮和表单有稳定的可访问名称。导航、对话框与滚动容器需支持键盘和正常点击。Electron 冒烟按真实可见交互检查，不通过强制点击或 DOM 内执行按钮 handler 绕过布局问题。保留空状态、服务离线、加载、取消和失败反馈。

设计稿/静态原型是历史探索；最终页面能力以真实数据流为准。改变界面名称或导航必须同步更新相关冒烟场景。
