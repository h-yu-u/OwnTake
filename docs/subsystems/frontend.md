# 前端工作区

## 责任

[WorkspaceApp](../../apps/web/src/WorkspaceApp.vue) 装配全局导航、项目选择和功能状态；`views/` 表达页面，`components/` 复用具体交互，`composables/` 管理有生命周期的状态和数据请求，`lib/` 保存 API 客户端与纯辅助函数。复用 Vue 3、TypeScript 和 Naive UI，不再另造表单/弹窗基础库。

## 交互合同

故事库独立于当前项目；分镜、素材剪辑、创作工具、任务和导出按当前作品组织。项目切换和离开编辑前处理未保存内容；后台刷新不能悄悄覆盖用户输入。版本冲突保留编辑内容并给出重新载入/合并方向，不用“自动刷新”掩盖丢失。

生成前展示实际模型、输入、引用素材、能力冲突和费用预留；用户确认后提交一次。能力不足不能在前端擅自降级。进度、等待远端、未知、失败和需要人工审阅是不同状态。

[API 客户端](../../apps/web/src/lib/api.ts) 统一会话、CSRF、错误合同，不将密钥放入浏览器持久存储。桌面调用只能经过受限桥；Web 使用者不能依赖 Electron 才有的能力。

## 可访问性与验证

按钮和表单有稳定的可访问名称。导航、对话框与滚动容器需支持键盘和正常点击。Electron 冒烟按真实可见交互检查，不通过强制点击或 DOM 内执行按钮 handler 绕过布局问题。保留空状态、服务离线、加载、取消和失败反馈。

设计稿/静态原型是历史探索；最终页面能力以真实数据流为准。改变界面名称或导航必须同步更新相关冒烟场景。
