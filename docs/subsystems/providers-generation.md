# 模型连接与生成

## 责任

`packages/providers/` 负责协议编译、能力校验和受限网络访问；服务端 repository 保存连接、调用与预算，runner 执行持久任务。Provider 是模型 API，Runtime 是可选本机 Agent/CLI，两者不互相冒充。

统一 OpenAI 连接可以复用凭据和发现模型，但模型列表不是能力证明。兼容端点明确协议与模型，已知模型可按官方参考配置自动填入输入模式、比例、时长、参考数量；未知模型保留手动设置。不支持的能力应拒绝或要求重新规划，不能静默删掉引用、尾帧、声音或改用其他模型。

## 兼容连接的模型目录

兼容连接输入 Key 后，界面等待输入稳定再自动读取模型，可搜索选择、手填 ID 或手动刷新；编辑已有连接可在相同服务来源使用已保存的 Key。读取失败或目录为空不阻止手填，刷新不会覆盖已选模型。根据明确的领域 / 输出模态筛选当前用途；没有用途元数据的 ID 仍可选择，不把目录可见性当作推理权限或完整能力证明。

`POST /api/providers/models` 在现有会话 / CSRF 保护下接收草稿地址与 Key，或已有连接 ID。应用边界校验地址与凭据来源，适配层只向规范化 Base URL 的 `/models` 发起一次有超时及响应大小限制的 GET，不跟随重定向、不探测其他地址、不生成内容，也不保存草稿 Key 或修改已存配置。Ark 使用其 [Models API](https://docs.volcengine.com/docs/ark/models-api?lang=zh)，兼容服务需提供相同的目录路径和模型列表结构。

更换服务来源时清空输入 Key，并拒绝把已保存 Key 转发到新来源；Key、地址、类型变化或关闭弹窗都会作废旧目录和迟到回复。返回值仅包含经过校验的模型目录字段，供应商原错误正文不回显。相关边界见 [模型目录测试](../../tests/provider-models.test.ts) 与 [HTTP 测试](../../tests/provider-models-api.test.ts)；模拟端点验证不等于真实账号模型权限验收。

## 自动能力配置

Ark 模型目录提供模态信息，但未提供完整画幅、时长及参考图片数量。界面对 [明确登记的 Seedance 版本及别名](../../packages/providers/src/ark-model-capabilities.ts) 使用官方文档配置，选中后自动填入可提交能力、显示摘要与来源，手动表单收进高级设置。未知版本或自定义接入点不靠名称模糊推断，也不会沿用上个模型的参考图片设置。自动配置不发起推理或验证付费权限。

配置取模型文档和当前适配器的交集：画幅仅列应用支持的比例，时长使用明确整数秒，不启用自动时长、视频或音频参考；需要尚未实现的自适应画幅的输入方式不自动开放。模型图片上限超过本机接口时使用本机上限并说明差异。配置是纯函数，每次返回独立数据，不修改已保存连接或冻结任务。

高级设置允许手动调整，保存后再次打开会保留该调整，不因目录刷新而覆盖；可显式恢复自动配置，切换模型则使用新模型规则。能力规则回归见 [自动能力测试](../../tests/ark-model-capabilities.test.ts)，真实供应商权限与结果仍需独立验收。

## 冻结、幂等与成本

在付费请求前保存操作 ID、请求摘要、模型目标、凭据版本引用、输入资产与修订，以及存在时的额度预留。同一 ID 重复请求返回原操作；同一 ID 对应不同参数必须冲突。单镜图片 / 视频界面不提交本地预留，任务以 `budgetMode: none` 保存且真实费用保持未知；兼容旧调用方的可选预算校验仍生效，历史记录及预留不修改。预算记录是用户的预留/核对，不是假装供应商最终账单。

[GenerationRepository](../../apps/server/src/generation-repository.ts) 与 [GenerationRunner](../../apps/server/src/generation-runner.ts) 区分提交、远端等待、已成功待下载、入库、失败与取消。未知提交不自动重发；已知任务只轮询/下载原结果。取消本机等待不等于供应商取消，也不能假定没有收费。

输出先校验并保存完整接收证据，随后登记 Artifact 与候选。迟到结果保留其原视觉版本。只修改字幕/剪辑不应该重新付费生成画面。

HTTP 拒绝提示仅保留白名单中的供应商错误码，不回显错误原文或任意标识。Ark 的 `ModelNotOpen`、`InvalidEndpointOrModel.NotFound`、`InvalidEndpointOrModel.ModelIDAccessDisabled`、`PathNotFound` 和 `InvalidAction` 分别提示开通、权限 / 模型、接入点和路由问题；没有具体错误码的 404 不应直接判定为模型不存在。依据见 [Ark 错误码](https://docs.volcengine.com/docs/ark/error-codes?lang=zh)。模型目录可见、任务列表查询成功均不代表已开通生成权限，不能以此自动标记实接验证通过。已保存的旧通用错误不伪造补全，也不通过重发付费请求恢复诊断。

## 凭据与外发

[CredentialVault](../../apps/server/src/credentials.ts) 仅在服务端使用；本地受限文件不是应用级加密。密钥不进入 HTTP 响应、错误正文、项目备份和日志。改变服务来源不能把原密钥自动发给另一个域名。模型返回的 URL/文本是外部输入，不授予任意文件或网络权限。

## 验证

模拟供应商测试覆盖超时、断连、重复提交、取消竞态、损坏回复、下载失败与费用未知。真实账号、收费请求及实际画面质量需另行授权和记录，不进入每次 PR 的普通回归。配置声明始终显示其真实验证状态。
